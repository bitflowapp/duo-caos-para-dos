# DUO — Caos para Dos 🎮❤️

Videojuego cooperativo y competitivo para dos personas, cada una desde su celular, con aventura, humor y romance.

## Objetivo de la primera versión
- Acceso web en Safari iOS y Chrome Android sin instalar apps ni registrarse.
- Salas privadas de exactamente dos jugadores con enlaces/códigos de invitación.
- Multijugador real con servidor autoritativo, sincronización y reconexión.
- Tres minijuegos **terminados y pulidos**: Carrera del Caos, Sincronizados y ¿Cuánto me conocés?
- Gráficos originales, controles táctiles, sonido, resultados y revancha.

## Stack sugerido
TypeScript estricto, Phaser 3, Vite, Node.js y Colyseus o Socket.IO (evaluar elección), Vitest, Playwright y GitHub Actions. Monorepo opcional: `apps/web`, `apps/server`, `packages/shared`.
